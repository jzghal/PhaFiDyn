# PhaFiDyn: " Phase-Field damage model in Dynamic framework "
PhaFiDyn is an implementation of the phase-field method for simulating damage in brittle or quasi-brittle materials within a Dynamic framework. It can be adapted to other structures or mechanical behaviors.

    • Requires FEniCS 2019.1.0. Download and installation instructions can be found at https://fenicsproject.org/download/archive/
    • Updates to this implementation, as well as the test cases, are available on this Git repository,
    • ParaView results are available at the following sharing link : https://drive.google.com/file/d/1WQByrmx9p3YasyXKiL6Oxv0hHQXIFxW0/view?usp=drive_link
    • For any questions or suggestions, please contact Jihed ZGHAL (jzghal@parisnanterre.fr) or Abdelmalek BARKI (abarki@parisnanterre.fr).

This implementation was developed as part of the research conducted within the Mechanical Engineering of Materials, Structures, and Systems (M2S2) Division of the “Laboratoire d'Énergétique et de Mécanique Électrique” (LEME-EA4416).
